# twf-docker

Готовый Docker-образ [ton-wallet-finder](https://github.com/lendel/ton-wallet-finder) для
облачных CPU-подов (RunPod и любой Docker-хост). Образ ищет TON-кошелёк, адрес которого
заканчивается на нужные вам символы. Укажите команду при запуске пода, и образ выполнит её.

```
ghcr.io/lendel/twf-docker:latest
```

- Сам определяет число ядер пода, в том числе лимит cgroup, и запускает поиск на всех.
- Раз в минуту пишет в лог прогресс: попытки, скорость, вероятность того, что адрес уже
  должен был найтись, и время до 50%-й отметки.
- С паролем `TWF_PASSWORD` сохраняет результат в зашифрованном виде (scrypt + AES-256-GCM)
  и дублирует зашифрованную копию в лог.
- На RunPod контейнер после завершения не выходит, а остаётся работать. Так под не
  перезапустится в новый платный поиск, а вы спокойно заберёте результат.
- SSH поднимается автоматически по ключу из настроек RunPod (`PUBLIC_KEY`). Вход по паролю
  отключён.

## Быстрый старт на RunPod

1. **Pods → Deploy → CPU.** Выберите **5 GHz / Compute-Optimized**. Ядро на нём заметно
   быстрее, а стоит лишь чуть дороже, поэтому каждый найденный адрес обходится дешевле.
2. **Change Template → New Template**, затем заполните:
   - **Container Image:** `ghcr.io/lendel/twf-docker:latest`
   - **Container Start Command:** нужная команда, например `find abc --wallet v5r1`
     (полный список ниже).
   - **Container Disk:** 5 GB вполне хватит.
   - **Volume Disk** (рекомендуется, 1 GB): смонтируйте в `/workspace`. Результаты
     сохраняются туда и не пропадут при остановке пода.
   - **Expose TCP Ports:** `22`. Нужно, только если хотите заходить по SSH.
   - **Environment Variables:** `TWF_PASSWORD` = ваш пароль. Лучше хранить его как RunPod
     Secret и указать значение `{{ RUNPOD_SECRET_twf_password }}`.
3. **Deploy.** Ход поиска виден во вкладке **Logs**.
4. Когда в логе появится `FOUND`, заберите результат (см. ниже), а затем **остановите
   и удалите под вместе с volume**: под оплачивается всё время, пока он запущен.

> Если поле Start Command не подходит, команду можно задать только переменными окружения:
> `TWF_ENDING=abc`, `TWF_WALLET=v5r1` и т. д. Тогда Start Command оставьте пустым.

### Как забрать результат

**Вариант A: из лога (с `TWF_PASSWORD`).** В логе есть блок
`-----BEGIN TWF ENCRYPTED RESULT-----`. Скопируйте одну строку JSON между маркерами в
файл `result.enc.json` у себя на компьютере и расшифруйте локально:

```bash
docker run --rm -e TWF_PASSWORD='ваш пароль' -v "$PWD:/results" \
  ghcr.io/lendel/twf-docker:latest decrypt result.enc.json
```

Файл совместим с `decryptResults()` из библиотеки ton-wallet-finder.

**Вариант B: через Web Terminal или SSH пода.**

```bash
twf list                                     # где лежат файлы
twf decrypt ton_wallet_results.enc.json      # TWF_PASSWORD уже задан в поде
cat /workspace/ton_wallet_results.txt        # если запускали без пароля
```

После этого импортируйте 24 слова в кошелёк (Tonkeeper, MyTonWallet, …) и выберите ту же
версию контракта, что указали при поиске.

## Список команд

Эти команды пишутся в **Container Start Command** (или после имени образа в `docker run`).
Слово `twf` в начале можно писать или не писать: `find abc` и `twf find abc` работают
одинаково.

### Поиск

| Команда | Что делает |
|---|---|
| `abc` | Короткая форма: то же, что `find abc` |
| `find abc` | Ищет адрес на `…abc` (кошелёк v4r2, все ядра) |
| `find abc --wallet v5r1` | То же для кошелька **W5 (v5r1)**. Его по умолчанию создаёт Tonkeeper |
| `find abc --wallet v3r2` | Для старого контракта v3r2 |
| `find TON --count 3` | Найти **3** разных кошелька на `…TON` подряд |
| `find abc --workers 16` | Явно задать число потоков (по умолчанию `auto`) |
| `find abc --out /workspace/run1` | Сохранять результаты в другую папку |
| `find abc --progress 300` | Писать прогресс раз в 5 минут вместо минуты |
| `find abc --print-secret` | Также вывести 24 слова и ключи **в лог**. Удобно, но лог хранится у RunPod, так что лучше этим не пользоваться |
| `find bench` / `find list` | Если окончание совпадает с названием команды, обязательно пишите `find` |

Окончание **чувствительно к регистру**. Допустимые символы: `A–Z a–z 0–9 - _`, не больше 46.
Каждый добавленный символ делает поиск примерно в 64 раза дольше.

### Оценка скорости и цены

| Команда | Что делает |
|---|---|
| `bench` | 30 секунд меряет скорость пода и печатает время для окончаний от 1 до 6 символов |
| `bench --price 1.12` | То же плюс колонка средней стоимости (цена пода в $/час) |
| `bench --seconds 60 --wallet v5r1` | Более долгий замер, для другой версии кошелька |
| `estimate 4 --rate 500 --price 1.12` | Расчёт без замера: 4 символа при 500 адр/с |
| `estimate abcd --rate 500` | То же, длина берётся из самого окончания |
| `cores` | Сколько ядер видит контейнер и сколько потоков возьмёт `auto` |

### Результаты и служебные

| Команда | Что делает |
|---|---|
| `list` | Список файлов результатов |
| `decrypt <файл>` | Расшифровать результат (нужен `TWF_PASSWORD`) |
| `version` | Версии образа, ton-wallet-finder и Node.js |
| `help` | Справка. Её же образ выводит, если команда не указана |
| `bash` | Запустить оболочку вместо twf (для отладки) |

### Все опции

| Опция | Переменная окружения | По умолчанию | Значение |
|---|---|---|---|
| `-w, --wallet` | `TWF_WALLET` | `v4r2` | Версия контракта: `v3r2`, `v4r2`, `v5r1` |
| `-j, --workers` | `TWF_WORKERS` | `auto` | Число потоков. `auto` = лимит CPU пода |
| `-n, --count` | `TWF_COUNT` | `1` | Сколько кошельков найти |
| `-o, --out` | `TWF_OUT` | `/workspace`, иначе `/results` | Папка результатов |
| `-t, --seconds` | `TWF_BENCH_SECONDS` | `30` | Длительность `bench` |
| `-r, --rate` | `TWF_RATE` | — | Скорость (адр/с) для `estimate` |
| `-p, --price` | `TWF_PRICE_PER_HOUR` | — | Цена пода в $/час для колонки стоимости |
| `--progress` | `TWF_PROGRESS` | `60` | Как часто печатать прогресс, в секундах |
| `--print-secret` | `TWF_PRINT_SECRET=1` | выкл. | Печатать мнемонику в лог |
| — | `TWF_PASSWORD` | — | Пароль шифрования результатов (**очень рекомендуется**) |
| — | `TWF_ENDING` | — | Окончание, если команда не указана |
| — | `TWF_KEEP_ALIVE` | `1` на RunPod, `0` иначе | Не завершать контейнер после команды |

Опции из командной строки важнее переменных окружения.

## Сколько это займёт

Скорость примерно **10–12 адресов/с на vCPU** при 2.3 GHz. На более быстрых ядрах она выше.
Точную цифру для вашего пода покажет `bench`. Прикидка для 32 vCPU (~300–600 адр/с):

| Символов | Попыток в среднем | Время | Цена на 32 vCPU 5 GHz ($1.12/ч) |
|---|---|---|---|
| 3 | 262 тыс. | ~7–15 мин | ~$0.2 |
| 4 | 16,8 млн | ~8–16 ч | ~$9–17 |
| 5 | 1,07 млрд | ~3–6 недель | ~$500–1000 |

Время средние. Конкретный запуск может закончиться в разы быстрее или медленнее
(распределение геометрическое). Размер пода почти не влияет на итоговую цену: цена и
скорость растут вместе, поэтому больше ядер — это просто быстрее.

## Локально или на любом сервере

```bash
docker run --rm ghcr.io/lendel/twf-docker:latest bench
docker run --rm -e TWF_PASSWORD='пароль' -v "$PWD:/results" \
  ghcr.io/lendel/twf-docker:latest find abc --wallet v5r1
```

Вне RunPod контейнер сразу завершается после команды. Чтобы оставить его работать,
задайте `TWF_KEEP_ALIVE=1`.

## Безопасность

- Мнемоника создаётся на чужом сервере. Всегда задавайте `TWF_PASSWORD`, а после поиска
  **удаляйте под и volume**.
- Не держите на найденном адресе крупные суммы: у провайдера формально был доступ к
  машине. Для серьёзных сумм запускайте поиск на своём железе.
- В лог попадает только адрес и зашифрованный блок. Мнемоника туда пишется, только если
  явно указать `--print-secret`.
- Внутри образа: `node:24-bookworm-slim` (закреплён по digest), `ton-wallet-finder`
  (точная версия по `package-lock.json`, без runtime-зависимостей), `tini`, `openssh-server`.

## Сборка и публикация

Workflow `.github/workflows/docker.yml` прогоняет тесты, собирает образ и делает
smoke-тест (настоящий поиск 1 символа и расшифровку). Затем публикует образ в GHCR:

- push в `main` → `:latest` и `:sha-xxxxxxx`;
- тег `v1.2.3` → `:1.2.3`.

> **Важно:** пакет, только что опубликованный в GHCR, по умолчанию **приватный**. Один раз
> откройте *GitHub → Packages → twf-docker → Package settings → Change visibility → Public*.
> Иначе RunPod не сможет скачать образ без учётных данных реестра.

```bash
npm ci && npm test          # юнит-тесты CLI
docker build -t twf .       # локальная сборка
```
